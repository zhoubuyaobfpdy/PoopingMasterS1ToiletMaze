# 🚽 厕所迷宫 · 第一关

一个用 HTML5 Canvas 制作的迷宫追逃小游戏，**纯静态网页，无需服务器**，可直接部署到 GitHub Pages。

## 玩法

你急需上厕所，但误入了一个迷宫，一个"小屎人"正在追你……
在被追到之前找到营业的厕所！

- 🏃 玩家用方向键 / WASD 移动
- 💩 小屎人用 BFS 追击你
- 🚽 厕所有营业的和废弃的，**外观一样**，踩上去才知道
- ⭐ 收集星星提升星级（3星满分）
- ⚡ 加速器：速度+50%，持续5秒
- ❄️ 冰冻球：冻住小屎人5秒
- 👻 隐身球：隐身3秒，可穿墙/安全穿越死路和废弃厕所
- 💣 死路：踩到即失败！（隐身穿墙时除外）
- 玩家速度是小屎人的1.5倍

## 排行榜

排名规则：**成功通关次数少→多**，然后**星星多→少**

排行榜数据通过 URL 参数传递——把游戏链接发给朋友，他们打开就能看到你的成绩并挑战！

## 部署到 GitHub Pages

1. 把这些文件上传到 GitHub 仓库
2. 进入仓库 **Settings → Pages**
3. Source 选 **main** 分支，文件夹选 **/(root)**
4. 点 **Save**
5. 等几分钟，GitHub 会给你一个 `https://你的用户名.github.io/仓库名/` 的链接
6. 把这个链接发给朋友就能一起玩了！

## 文件说明

- `toilet_maze.html` — 游戏主页面（包含全部游戏逻辑 + 排行榜）
- `index.html` — 自动跳转到游戏页面
- `leaderboard.html` — 独立排行榜页面（可选）

## 技术栈

- 纯前端：HTML5 Canvas + 原生 JavaScript
- 无后端、无依赖、无构建工具
- 排行榜数据：URL 参数传递（Base64 编码）
